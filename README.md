# REST API Server in Go

This repository contains a simple REST API server written in Go. The server exposes endpoints to create, list, retrieve, and delete items, with data stored in memory (no persistent storage). This project is designed for quick setup, development in VS Code, and includes a CI pipeline using GitHub Actions.

## Repository

This project is maintained by [alinaveed62](https://github.com/alinaveed62).

## Prerequisites

- [Go 1.18 or later](https://golang.org/dl/)
- [VS Code](https://code.visualstudio.com/) (optional, for development)
